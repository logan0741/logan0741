## 백지에서 팀과 시스템을 세우는 개발자, 김건희입니다

</div>

- 전남대학교 인공지능학부 4학년. 책보다 현장에서 배우며 성장하는 것을 좋아합니다.
- 신설 학과 첫 과대표부터 동아리 회장, 대회 팀장까지, 아무것도 없는 곳에서 팀을 꾸리고 굴리는 일을 반복해 왔습니다.
- 텍스트, 시계열, 음성, 비전, 오디오, Web3, 모바일을 거쳐 지금은 ETRI 연구연수생으로 실물 로봇 VLA 실험을 하고 있습니다.
- 4년간 대회와 공모전 15회, 팀장 8회, 수상 4회, 그리고 ICRA 2027 논문 투고(2저자)로 결과를 남겼습니다.
- 성공보다 실패의 이유를 기록하는 데 더 시간을 씁니다. 다음 프로젝트가 거기서 시작되기 때문입니다.
